# Accrochage

Calculateur de hauteur de clous pour l'accrochage de tableaux.

Application web autonome — HTML, CSS et JavaScript regroupés dans un fichier
`index.html` unique. Conçue pour usage mobile avec ajout à l'écran d'accueil
iPhone (PWA).

## Fonctionnalités

- **Tableau seul** — position du clou pour un cadre unique, avec alignement par
  axe central, haut ou bas du cadre.
- **Alignement** — alignement horizontal de plusieurs tableaux côte à côte
  (milieu, haut ou bas).
- **Grille** — disposition en grille (R lignes × C colonnes) avec espacements
  horizontal et vertical paramétrables, et prévisualisation SVG du résultat.

## Mise en ligne

Le fichier `index.html` est servi tel quel par GitHub Pages depuis la branche
`main`, dossier racine.

URL : _à compléter après activation de Pages_

## Mise à jour

Modifier `index.html` directement via l'interface web GitHub (bouton crayon →
édition → Commit changes), puis attendre 1-2 minutes pour la propagation.
Le versionnage Git permet de revenir à n'importe quelle version précédente
si nécessaire.
